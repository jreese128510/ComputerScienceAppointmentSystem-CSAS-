# CSAS (Computer Science Appointment System)

## Project Overview

CSAS is a web\-based Student Appointment Management System developed for the CSC architecture and design project. The system allows students to schedule appointments with professors through an easy\-to\-use web interface.

Current Features:

- Home Dashboard
- Appointment Scheduling Form
- Professor Selection
- Appointment Confirmation Message
- Responsive Mobile\-Friendly Design

---

## Team Setup Instructions

### Prerequisites

Install the following software:

- Visual Studio Code
- Live Server VS Code Extension

---

## Running the Project Locally

### 1\. Clone the Repository

### git clone <repository\-url>2. Open the Project in VS Code

Open the project folder in Visual Studio Code.

Example:

CSAS/

├── backend/

├── frontend/

│   ├── index.html

│   ├── appointments.html

│   └── ...

### 3\. Install Live Server

In VS Code:

1. Open Extensions
2. Search for "Live Server"
3. Install the extension by Ritwick Dey

### 4\. Launch the Website

Right\-click:

frontend/index.html

Select:

Open with Live Server

The website will automatically open in your browser.

Example URL:

[http://127.0.0.1:5500/frontend/index.html](http://127.0.0.1:5500/frontend/index.html)

## Notes

- No database connection is currently required to run the interface.
- Appointment data is displayed on\-screen only and is not yet permanently stored.
- Future development will integrate the frontend with the Express backend and SQLite database.
